# Filters

| Module | Description | API |
| --- | --- | --- |
| [Blur](./blur/README.md) | Gaussian, motion, spin or zoom blur (interactive center) | [API](./blur/api.md) |
| [Motion blur](./motionBlur/README.md) | Directional, zoom or spin blur (speed, trails, impacts) | [API](./motionBlur/api.md) |
| [Sharpness](./sharpen/README.md) | Enhances details and edges (unsharp mask) | [API](./sharpen/api.md) |
| [Denoise](./denoise/README.md) | Reduces noise while preserving edges (median filter) | [API](./denoise/api.md) |
| [Edge detection](./edgeDetect/README.md) | Extracts edges (Sobel) with dual threshold, colors and pre-blur | [API](./edgeDetect/api.md) |
| [Chromatic aberration](./chromatic/README.md) | Shifts the red and blue channels (lens effect, glitch, impact) | [API](./chromatic/api.md) |
| [Dilate / Erode](./morphology/README.md) | Thickens or shrinks opaque areas (masks, outlines, silhouettes) | [API](./morphology/api.md) |
| [Normal map](./normalMap/README.md) | Generates a normal map from a heightmap (relief for 3D engines / VFX) | [API](./normalMap/api.md) |
| [Pixelate](./pixelate/README.md) | Reduces the image to large pixels (pixel art effect) | [API](./pixelate/api.md) |
| [Halftone](./halftone/README.md) | Dot screen, ordered dithering (Bayer) or error diffusion (retro / print) | [API](./halftone/api.md) |
| [Painting](./kuwahara/README.md) | Painterly flat areas that preserve edges (Kuwahara filter, oil effect) | [API](./kuwahara/api.md) |
| [Pixel sorting](./pixelSort/README.md) | Sorts pixels by luminance in bright or dark areas (glitch art) | [API](./pixelSort/api.md) |
| [CRT scanlines](./scanlines/README.md) | Scan lines and RGB mask in CRT screen style | [API](./scanlines/api.md) |
| [Light rays](./rays/README.md) | Volumetric rays emitted by bright areas from a center (god rays) | [API](./rays/api.md) |
| [Feather](./feather/README.md) | Softens transparency edges (alpha mask fade) | [API](./feather/api.md) |
| [Vignette](./vignette/README.md) | Progressively darkens the image edges | [API](./vignette/api.md) |
| [Bloom](./bloom/README.md) | Diffuses bright areas into an additive halo (glow) | [API](./bloom/api.md) |
| [Remove solid background](./removeBg/README.md) | Makes a single-color background (green screen, studio…) transparent, detected or picked. | [API](./removeBg/api.md) |
| [Split RGB](./splitRgb/README.md) | Splits the image into its Red, Green and Blue channels | [API](./splitRgb/api.md) |
| [Split transparency](./splitAlpha/README.md) | Splits the image into its color channel (opaque RGB) and its alpha channel (grayscale) | [API](./splitAlpha/api.md) |
