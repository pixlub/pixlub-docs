# Adjustment

| Module | Description | API |
| --- | --- | --- |
| [Basic adjustment](./baseAdjust/README.md) | The essential photo settings in one place: light, tones, white balance and colours | [API](./baseAdjust/api.md) |
| [Levels](./levels/README.md) | Adjusts the black and white points, gamma and output range, per channel | [API](./levels/api.md) |
| [White balance](./whiteBalance/README.md) | Warms or cools the picture and corrects its green or magenta cast | [API](./whiteBalance/api.md) |
| [Recolour](./recolor/README.md) | Tints the whole picture with a single colour, keeping its shadows and highlights | [API](./recolor/api.md) |
| [HSL](./hsl/README.md) | Shifts the hue, saturation and lightness of a colour range | [API](./hsl/api.md) |
| [Black and white](./blackWhite/README.md) | Turns the picture grey, setting how light each colour becomes | [API](./blackWhite/api.md) |
| [Brightness & Contrast](./brightness/README.md) | Adjusts brightness and contrast | [API](./brightness/api.md) |
| [Posterize](./posterize/README.md) | Reduces the number of levels per channel (stylized flats, cel shading) | [API](./posterize/api.md) |
| [Exposure](./exposure/README.md) | Raises or lowers the light of the picture, stop by stop like a camera | [API](./exposure/api.md) |
| [Curves](./curves/README.md) | Adjusts tone with an editable curve, per channel or global | [API](./curves/api.md) |
| [Saturation / hue curves](./hueSatCurves/README.md) | Sets saturation or hue according to the luminance, saturation or hue of each colour | [API](./hueSatCurves/api.md) |
| [Channel mixer](./channelMixer/README.md) | Rebuilds each channel from the others, in the chosen space | [API](./channelMixer/api.md) |
| [Invert](./invert/README.md) | Turns the picture into its negative | [API](./invert/api.md) |
| [Color balance](./colorBalance/README.md) | Adjusts hues per tonal range (highlights, midtones, shadows), maskable | [API](./colorBalance/api.md) |
| [Accessibility filter](./colorAccessibility/README.md) | Corrects colours so they stay readable for colour-blind vision | [API](./colorAccessibility/api.md) |
| [Palette: recolor](./paletteRemap/README.md) | Generates a recolored variant of the image for each palette color (batch) | [API](./paletteRemap/api.md) |
| [Threshold](./threshold/README.md) | Binarizes luminance against a threshold (with a soft transition) | [API](./threshold/api.md) |
| [Replace colors](./replaceColors/README.md) | Replaces a list of source colors with target colors | [API](./replaceColors/api.md) |
| [Opacity](./opacity/README.md) | Changes the image opacity | [API](./opacity/api.md) |
| [Outline](./outline/README.md) | Adds an outline to the image | [API](./outline/api.md) |
| [Shadow](./shadow/README.md) | Casts a shadow (outer or inner) from the image alpha | [API](./shadow/api.md) |
| [Gradient map](./gradientMap/README.md) | Colorizes the image by mapping its luminance onto a gradient | [API](./gradientMap/api.md) |
