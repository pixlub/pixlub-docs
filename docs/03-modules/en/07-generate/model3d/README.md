# 3D model

Imports a 3D model (GLB, GLTF, OBJ, FBX, STL): camera, materials and animation. To be merged onto an image with “3D model merge”.

**Category** : Generation · **Identifier** : `model3d`

## Where to use it

- **[Image graph](https://pixlub.com/en/image/graph)** : Connect it to other modules to build a richer effect.

## Inputs

This module has no input: it creates the image from its settings alone.
