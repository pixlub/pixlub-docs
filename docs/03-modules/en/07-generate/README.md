# Generation

| Module | Description | API |
| --- | --- | --- |
| [Noise](./noise/README.md) | Generates procedural noise (Perlin, simplex, random, Voronoi, spots, cubist, shards) with post-processing and blending | [API](./noise/api.md) |
| [Draw a mask](./drawShape/README.md) | Draws precise shapes (curves) combined by add/subtract — mask output | — |
| [Solid](./solid/README.md) | Generates a shape filled with a solid color or a gradient | [API](./solid/api.md) |
| [Palette](./palette/README.md) | Defines a color palette to reuse in the graph | — |
| [Palette from gradient](./paletteFromGradient/README.md) | Samples a gradient into a fixed number of colors | — |
| [Palette from image](./paletteFromImage/README.md) | Extracts the dominant colors of an image (median cut) | [API](./paletteFromImage/api.md) |
| [3D model](./model3d/README.md) | Imports a 3D model (GLB, GLTF, OBJ, FBX, STL): camera, materials and animation. To be merged onto an image with “3D model merge”. | — |
| [Pattern](./checker/README.md) | Generates a repeating pattern: checkerboard, grid, dots, stripes, bricks, honeycomb | — |
| [Gradient](./gradient/README.md) | Generates a linear, circular, radial or diamond gradient | — |
| [QR code](./qrcode/README.md) | Generates a QR code any reader can scan (link, Wi-Fi, contact…), styled, with a logo, or blended into an image | [API](./qrcode/api.md) |
| [Lens flare](./flare/README.md) | Optical flare: core, star branches, chromatic halo and ghost reflections | — |
| [Radial glow](./glow/README.md) | Generates a radial glow (core, glow, aura) with falloff control | — |
| [Lightning](./lightning/README.md) | Generates a branching procedural lightning bolt between two points | — |
| [Path](./pathStroke/README.md) | Draws vector paths: pen, pencil, shapes, tapered strokes and fills | — |
| [Particles](./particles/README.md) | Scatters a source image (or a mix of images from a batch) into particles (emission shape, trails, falloff), driven by a seed | [API](./particles/api.md) |
