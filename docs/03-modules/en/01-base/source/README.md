# Source image

Loads an image from a file and feeds it to the graph.

**Category** : Base modules · **Identifier** : `source`

## Where to use it

- **[Image graph](https://pixlub.com/en/image/graph)** : Connect it to other modules to build a richer effect.

## Inputs

This module has no input: it creates the image from its settings alone.

> [!NOTE]
> **Guide coming soon**
>
> This module has no detailed guide yet. Its settings show their description in the app; the API view lists each of them with its limits.

## Export

The **Download** button saves the result in the format of the imported file: a JPEG photo comes out as JPEG. The menu on its right opens the **Export settings** to pick another format, set the quality, size or background, and offers **Copy image**.

- **[The export dialog](../../../../01-app/en/02-image/04-exportation.md)** : Every format, its settings, local or server processing, batches and the local folder.
