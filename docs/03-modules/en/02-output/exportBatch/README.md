# Export a batch

Downloads every image of a batch: an archive, separate files or an animation.

**Category** : Output · **Identifier** : `exportBatch`

## Where to use it

- **[Image graph](https://pixlub.com/en/image/graph)** : Connect it to other modules to build a richer effect.

## Inputs

The files the module page accepts: drop them on the import area, or click it to browse. A file in another format is set aside, with a message listing the allowed formats.

| Input | Accepted formats | Files |
| --- | --- | --- |
| **Batch** (required)<br />Batch whose images are all downloaded. | `PNG`, `JPEG`, `WebP`, `GIF`, `AVIF`, `BMP` | Up to 64 files, gathered in a batch |
