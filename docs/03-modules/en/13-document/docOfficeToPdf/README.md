# Office to PDF

Convert a Word, Excel, PowerPoint or OpenDocument file to PDF.

**Category** : Documents · **Identifier** : `docOfficeToPdf`

## Where to use it

- **[Module page](https://pixlub.com/en/module/docOfficeToPdf)** : Drop your files, adjust, download: the module on its own, nothing else.

## How to use

1. **Sign in**

   The conversion runs on our servers: an account is required.

2. **Import**

   Drop a .docx, .xlsx, .pptx, .odt… file.

3. **Run**

   The price in credits shows before the conversion.

## Tips

- The privacy badge reads "Sent to the server" as soon as the file is ready to go.
