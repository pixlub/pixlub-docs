# HTML to PDF

Lay out an HTML file and render it as a PDF, with selectable text.

**Category** : Documents · **Identifier** : `docHtmlToPdf`

## Where to use it

- **[Module page](https://pixlub.com/en/module/docHtmlToPdf)** : Drop your files, adjust, download: the module on its own, nothing else.

## How to use

1. **Sign in**

   The layout runs on our servers: an account is required.

2. **Import**

   Drop an .html file.

3. **Run**

   The price in credits shows before the render.

## Tips

- Images must be embedded in the file or available online.
