# Composition

| Module | Description | API |
| --- | --- | --- |
| [Split channels](./channelSplit/README.md) | Extracts the R, G, B and Alpha channels as channels (grayscale) | [API](./channelSplit/api.md) |
| [Merge channels](./channelMerge/README.md) | Rebuilds an image from R, G, B and/or Alpha channels | [API](./channelMerge/api.md) |
| [Image to mask](./imageToMask/README.md) | Converts an image into a mask channel (alpha, channel or luminance) | [API](./imageToMask/api.md) |
| [Merge](./merge/README.md) | Overlays one or more images (layers) on another | [API](./merge/api.md) |
| [Merge transparency](./mergeAlpha/README.md) | Recombines a color channel (RGB) and an alpha channel into a transparent image | [API](./mergeAlpha/api.md) |
| [Sprite sheet](./spriteSheet/README.md) | Assembles several images into a grid (flipbook, VFX atlas) | [API](./spriteSheet/api.md) |
| [Layout](./arrange/README.md) | Aligns several images side by side or stacked (banners, comparisons) | [API](./arrange/api.md) |
| [Assemble a batch](./arrayBatch/README.md) | Groups images and batches into a single batch | — |
| [Split a batch](./arraySplitBatch/README.md) | Splits a batch into individual images | — |
| [Mask](./mask/README.md) | Modulates an image's opacity by the luminance (or alpha) of a mask | [API](./mask/api.md) |
| [Eraser](./eraser/README.md) | Erases parts of the image by hand, with a palette of adjustable tips | [API](./eraser/api.md) |
| [3D model merge](./model3dMerge/README.md) | Renders a 3D model and overlays it on an image: position, rotation, scale. | — |
