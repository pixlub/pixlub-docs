# Split a batch

Splits a batch into individual images

**Category** : Composition · **Identifier** : `arraySplitBatch`

## Where to use it

- **[Image graph](https://pixlub.com/en/image/graph)** : Connect it to other modules to build a richer effect.

## Inputs

The files the module page accepts: drop them on the import area, or click it to browse. A file in another format is set aside, with a message listing the allowed formats.

| Input | Accepted formats | Files |
| --- | --- | --- |
| **Batch** (required)<br />Batch split into individual images, one per output. | `PNG`, `JPEG`, `WebP`, `GIF`, `AVIF`, `BMP` | Up to 64 files, gathered in a batch |

## Export

The **Download** button saves the result in the format of the imported file: a JPEG photo comes out as JPEG. The menu on its right opens the **Export settings** to pick another format, set the quality, size or background, and offers **Copy image**.

With several images, the button becomes **ZIP download**; the menu also offers separate files, or only the image on display.
