# Audio conversion

Convert a sound file to another format, with its settings.

**Category** : Conversion · **Identifier** : `convertAudio`

## Where to use it

- **[Module page](https://pixlub.com/en/module/convertAudio)** : Drop your files, adjust, download: the module on its own, nothing else.

## Inputs

The files the module page accepts: drop them on the import area, or click it to browse. A file in another format is set aside, with a message listing the allowed formats.

| Input | Accepted formats | Files |
| --- | --- | --- |
| **Sound** (required)<br />Sound file to convert. | `MP3`, `WAV`, `Ogg`, `FLAC`, `M4A`, `AAC`, `Opus`, `AIFF` | One file |

## How to use

1. **Import**

   Drop one or more sounds (MP3, WAV, Ogg, FLAC, M4A, AAC, Opus, AIFF): each gets its own workspace.

2. **Keep a part**

   Listen to it and drag the timeline handles.

3. **Pick the format**

   In the export window, with its bitrate, sample rate, channels or bit depth.

## Settings

| Setting | Effect |
| --- | --- |
| **Start / End** | Part of the sound kept, in seconds (0 at the end = to the end). |
| **Format** (export) | MP3, AAC, Opus, Vorbis, FLAC, WAV, AIFF, or original track (trimmed without re-encoding). |

## Tips

- Turning an MP3 into FLAC does not bring lost quality back: lossless keeps what is already there.
- Conversion happens in the browser, even for a format it cannot play.

## Export

The result is exported from the module page or the video editor, as MP4, WebM or another video container, without leaving your browser.

- **[The video editor](../../../../01-app/en/03-video/01-video-editor.md)** : Edit, tune the effects and export a video.
