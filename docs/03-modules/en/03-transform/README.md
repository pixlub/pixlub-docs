# Transformation

| Module | Description | API |
| --- | --- | --- |
| [Resize](./resize/README.md) | Changes the image dimensions | [API](./resize/api.md) |
| [Resize (Factor)](./resizeFactor/README.md) | Scales the image by a multiplication factor | [API](./resizeFactor/api.md) |
| [Extend](./extend/README.md) | Enlarges the image area without distorting the content | [API](./extend/api.md) |
| [Trim](./crop/README.md) | Crops an area of the image | [API](./crop/api.md) |
| [Auto crop](./trim/README.md) | Automatically trims transparent edges | [API](./trim/api.md) |
| [Rotation](./rotate/README.md) | Rotates the image | [API](./rotate/api.md) |
| [Mirror](./flip/README.md) | Flips the image horizontally and/or vertically | [API](./flip/api.md) |
| [Distortion](./skew/README.md) | Skews the image (horizontal and vertical shear) | [API](./skew/api.md) |
| [Corner pin](./cornerPin/README.md) | Moves the four corners of the image freely to put it in perspective | [API](./cornerPin/api.md) |
| [Sticker peel](./sticker/README.md) | Peels the image off like a sticker, curling it in a chosen direction | [API](./sticker/api.md) |
| [Translate](./translate/README.md) | Moves the texture in X and Y, in % of the image | [API](./translate/api.md) |
| [Transform](./transform/README.md) | Moves, rotates, scales, mirrors and fades the image in one go | [API](./transform/api.md) |
| [Puppet](./puppet/README.md) | Warps the image by moving pins on a mesh (puppet warp) | [API](./puppet/api.md) |
| [Polar](./polar/README.md) | Converts between rectangular and polar coordinates (rings, rays, halos) | [API](./polar/api.md) |
| [Ripple](./ripple/README.md) | Distortion in concentric rings around a center | [API](./ripple/api.md) |
| [Displacement](./displace/README.md) | Warps the image using a displacement map (noise, gradient…) | [API](./displace/api.md) |
| [Texture remap](./remap/README.md) | Redraws the image by reading, for each pixel, the position given by a map (gradient, noise…) | [API](./remap/api.md) |
| [Kaleidoscope](./kaleidoscope/README.md) | Repeats a sector in radial symmetry | [API](./kaleidoscope/api.md) |
| [Swirl](./twirl/README.md) | Twists the image into a spiral around a center | [API](./twirl/api.md) |
| [Wave](./wave/README.md) | Sinusoidal horizontal / vertical displacement | [API](./wave/api.md) |
| [Lens distortion](./fisheye/README.md) | Bulges (fisheye) or pinches (pincushion) the image around a center | [API](./fisheye/api.md) |
| [Seam offset](./tile/README.md) | Offsets the image with wrapping : check and build tileable textures | [API](./tile/api.md) |
| [Bend along path](./warpPath/README.md) | Warps an image along a path (ribbon / curved trail) | [API](./warpPath/api.md) |
| [Follow path](./followPath/README.md) | Moves an image along a path, from 0% to 100% of its length; the path may leave the frame | [API](./followPath/api.md) |
| [Trim](./trimVideo/README.md) | Trims a portion of the video at a given time. | — |
| [Speed](./speedVideo/README.md) | Speeds the video up or down. The output frame rate stays the same: what changes is which frames are pulled from the source. | — |
| [Frame rate](./frameRateVideo/README.md) | Rewrites the video frame rate. Lowering it shrinks the file; raising it above the source duplicates frames. | — |
