# Subtitles (video)

Transcribe a video's speech, word by word, and burn the subtitles into the picture.

**Category** : API services · **Identifier** : `transcribeVideoApi`

## Where to use it

- **[Video editor](https://pixlub.com/en/video/editor)** : Add it as an effect on a clip of your edit.

## Inputs

The files the module page accepts: drop them on the import area, or click it to browse. A file in another format is set aside, with a message listing the allowed formats.

| Input | Accepted formats | Files |
| --- | --- | --- |
| **Video** (required)<br />Video whose audio track is sent once to the server to be transcribed; subtitles are burned in in the browser. | `MP4`, `WebM`, `MOV`, `MKV` | One file |

## How to use

1. **Sign in**

   Transcription runs on our servers: an account is required.

2. **Import**

   Drop a video; only its audio track is sent, once.

3. **Style it**

   Font, colours, position, styles and spoken-word highlight, computed in your browser.

## Settings

| Setting | Effect |
| --- | --- |
| **Transcription** | Original language, characters per subtitle. |
| **Text** | Font, size, colour, outline, position and width. |
| **Styles** | Background, shadow, glow… stacked as in the Text module. |
| **Highlight** | Spoken word lit up, or text revealed letter by letter. |

## Tips

- Name the original language if the video opens on music.

## Export

The result is exported from the module page or the video editor, as MP4, WebM or another video container, without leaving your browser.

- **[The video editor](../../../../01-app/en/03-video/01-video-editor.md)** : Edit, tune the effects and export a video.
