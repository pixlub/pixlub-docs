# Conversion audio

Convertir un fichier son dans un autre format, avec ses réglages.

**Catégorie** : Conversion · **Identifiant** : `convertAudio`

## Où l'utiliser

- **[Page du module](https://pixlub.com/fr/module/convertAudio)** : Déposez vos fichiers, réglez, téléchargez : le module seul, sans rien d'autre.

## Entrées

Les fichiers que la page du module accepte : déposez-les sur la zone d’import, ou cliquez dessus pour parcourir. Un fichier d’un autre format est écarté, avec un message qui rappelle les formats permis.

| Entrée | Formats acceptés | Fichiers |
| --- | --- | --- |
| **Son** (obligatoire)<br />Fichier son à convertir. | `MP3`, `WAV`, `Ogg`, `FLAC`, `M4A`, `AAC`, `Opus`, `AIFF` | Un fichier |

## Utilisation

1. **Importer**

   Déposez un ou plusieurs sons (MP3, WAV, Ogg, FLAC, M4A, AAC, Opus, AIFF) : chacun a son espace de travail.

2. **Garder une partie**

   Écoutez-le et tirez les poignées de la timeline.

3. **Choisir le format**

   Dans la fenêtre d'export, avec son débit, sa fréquence, ses canaux ou sa profondeur.

## Réglages

| Réglage | Effet |
| --- | --- |
| **Début / Fin** | Partie du son gardée, en secondes (0 en fin = jusqu'au bout). |
| **Format** (export) | MP3, AAC, Opus, Vorbis, FLAC, WAV, AIFF, ou piste d'origine (découpe sans réencodage). |

## Astuces

- Repasser un MP3 en FLAC ne rend pas la qualité perdue : le sans-perte garde ce qui est déjà là.
- La conversion se fait dans le navigateur, même pour un format qu'il ne sait pas écouter.

## Exportation

Le résultat s’exporte depuis la page du module ou l’éditeur vidéo, en MP4, WebM ou un autre conteneur vidéo, sans quitter votre navigateur.

- **[L’éditeur vidéo](../../../../01-app/fr/03-video/01-video-editor.md)** : Monter, régler les effets et exporter une vidéo.
