# Conversion

| Module | Description | API |
| --- | --- | --- |
| [Extraction audio](./extractAudioVideo/README.md) | Sort la piste sonore d'une vidéo dans un fichier audio : MP3, AAC, Opus, FLAC, WAV… ou la piste d'origine telle quelle, sans perte. | — |
| [Conversion audio](./convertAudio/README.md) | Convertit un fichier son dans un autre format — MP3, AAC, Opus, Vorbis, FLAC, WAV ou AIFF — avec son débit, sa fréquence et ses canaux, et en garde la partie voulue. | — |
| [Conversion](./convert/README.md) | Convertit images, animations, vidéos et sons vers n’importe quel format de l’export : PNG, JPG, WebP, GIF, MP4, WebM, MP3, FLAC, WAV, PDF… | [API](./convert/api.md) |
