# Sous-titres (vidéo)

Transcrire la parole d'une vidéo, mot à mot, et graver les sous-titres dans l'image.

**Catégorie** : Services API · **Identifiant** : `transcribeVideoApi`

## Où l'utiliser

- **[Éditeur vidéo](https://pixlub.com/fr/video/editor)** : Posez-le en effet sur un plan du montage.

## Entrées

Les fichiers que la page du module accepte : déposez-les sur la zone d’import, ou cliquez dessus pour parcourir. Un fichier d’un autre format est écarté, avec un message qui rappelle les formats permis.

| Entrée | Formats acceptés | Fichiers |
| --- | --- | --- |
| **Vidéo** (obligatoire)<br />Vidéo dont la piste sonore est envoyée une fois au serveur pour être transcrite ; les sous-titres sont gravés dans le navigateur. | `MP4`, `WebM`, `MOV`, `MKV` | Un fichier |

## Utilisation

1. **Se connecter**

   La transcription passe par nos serveurs : un compte est demandé.

2. **Importer**

   Déposez une vidéo ; seule sa piste son part, une fois.

3. **Mettre en forme**

   Police, couleurs, position, styles et surlignage du mot prononcé, calculés dans votre navigateur.

## Réglages

| Réglage | Effet |
| --- | --- |
| **Transcription** | Langue d'origine, caractères par sous-titre. |
| **Texte** | Police, taille, couleur, contour, position et largeur. |
| **Styles** | Fond, ombre, lueur… empilés comme dans le module Texte. |
| **Surlignage** | Mot prononcé allumé, ou texte découvert lettre à lettre. |

## Astuces

- Indiquez la langue d'origine si la vidéo commence par de la musique.

## Exportation

Le résultat s’exporte depuis la page du module ou l’éditeur vidéo, en MP4, WebM ou un autre conteneur vidéo, sans quitter votre navigateur.

- **[L’éditeur vidéo](../../../../01-app/fr/03-video/01-video-editor.md)** : Monter, régler les effets et exporter une vidéo.
