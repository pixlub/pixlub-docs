# Exporter un batch

Télécharge toutes les images d'un batch : une archive, des fichiers séparés ou une animation.

**Catégorie** : Sortie · **Identifiant** : `exportBatch`

## Où l'utiliser

- **[Graphe d'image](https://pixlub.com/fr/image/graph)** : Reliez-le à d'autres modules pour composer un effet plus complexe.

## Entrées

Les fichiers que la page du module accepte : déposez-les sur la zone d’import, ou cliquez dessus pour parcourir. Un fichier d’un autre format est écarté, avec un message qui rappelle les formats permis.

| Entrée | Formats acceptés | Fichiers |
| --- | --- | --- |
| **Batch** (obligatoire)<br />Batch dont toutes les images sont téléchargées. | `PNG`, `JPEG`, `WebP`, `GIF`, `AVIF`, `BMP` | Jusqu’à 64 fichiers, réunis en un lot |
