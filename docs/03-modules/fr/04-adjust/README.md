# Ajustement

| Module | Description | API |
| --- | --- | --- |
| [Ajustement Base](./baseAdjust/README.md) | Les réglages essentiels d'une photo réunis : lumière, tons, balance des blancs et couleurs | [API](./baseAdjust/api.md) |
| [Niveaux](./levels/README.md) | Ajuste les points noir et blanc, le gamma et la plage de sortie, par canal | [API](./levels/api.md) |
| [Balance des blancs](./whiteBalance/README.md) | Réchauffe ou refroidit l'image et corrige sa dominante verte ou magenta | [API](./whiteBalance/api.md) |
| [Recolorer](./recolor/README.md) | Teinte toute l'image d'une seule couleur, en gardant ses ombres et ses lumières | [API](./recolor/api.md) |
| [HSL](./hsl/README.md) | Décale la teinte, la saturation et la luminosité d'une plage de couleurs | [API](./hsl/api.md) |
| [Noir et blanc](./blackWhite/README.md) | Passe l'image en gris en dosant la clarté de chaque couleur | [API](./blackWhite/api.md) |
| [Luminosité & Contraste](./brightness/README.md) | Ajuste la luminosité et le contraste | [API](./brightness/api.md) |
| [Postériser](./posterize/README.md) | Réduit le nombre de niveaux par canal (aplats stylisés, cel shading) | [API](./posterize/api.md) |
| [Exposition](./exposure/README.md) | Rehausse ou baisse la lumière de l'image, cran par cran comme un appareil photo | [API](./exposure/api.md) |
| [Courbes](./curves/README.md) | Ajuste la tonalité par une courbe éditable, par canal ou globale | [API](./curves/api.md) |
| [Courbes de saturation / teinte](./hueSatCurves/README.md) | Règle la saturation ou la teinte selon la luminance, la saturation ou la teinte de chaque couleur | [API](./hueSatCurves/api.md) |
| [Mélangeur de canaux](./channelMixer/README.md) | Recompose chaque canal à partir des autres, dans l'espace choisi | [API](./channelMixer/api.md) |
| [Inverser](./invert/README.md) | Passe l'image en négatif | [API](./invert/api.md) |
| [Balance des couleurs](./colorBalance/README.md) | Ajuste les teintes par plage de tons (clairs, moyens, foncés), masquable | [API](./colorBalance/api.md) |
| [Filtre d'accessibilité](./colorAccessibility/README.md) | Corrige les couleurs pour qu'elles restent lisibles par une vision daltonienne | [API](./colorAccessibility/api.md) |
| [Palette : recolorer](./paletteRemap/README.md) | Génère une variante recolorée de l'image par couleur de la palette (batch) | [API](./paletteRemap/api.md) |
| [Seuil](./threshold/README.md) | Binarise la luminance selon un seuil (avec transition douce) | [API](./threshold/api.md) |
| [Remplacer couleurs](./replaceColors/README.md) | Remplace une liste de couleurs sources par des couleurs cibles | [API](./replaceColors/api.md) |
| [Opacité](./opacity/README.md) | Modifie l'opacité de l'image | [API](./opacity/api.md) |
| [Contour](./outline/README.md) | Ajoute un contour à l'image | [API](./outline/api.md) |
| [Ombre](./shadow/README.md) | Projette une ombre (extérieure ou intérieure) à partir de l'alpha de l'image | [API](./shadow/api.md) |
| [Mappe dégradé](./gradientMap/README.md) | Colorise l'image en mappant sa luminance sur un dégradé | [API](./gradientMap/api.md) |
