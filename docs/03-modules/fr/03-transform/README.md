# Transformation

| Module | Description | API |
| --- | --- | --- |
| [Redimensionner](./resize/README.md) | Modifie les dimensions de l'image | [API](./resize/api.md) |
| [Redimensionner (Facteur)](./resizeFactor/README.md) | Met l'image à l'échelle par un facteur multiplicatif | [API](./resizeFactor/api.md) |
| [Étendre](./extend/README.md) | Agrandit la zone de l'image sans déformer le contenu | [API](./extend/api.md) |
| [Rogner](./crop/README.md) | Découpe une zone de l'image | [API](./crop/api.md) |
| [Recadrage auto](./trim/README.md) | Rogne automatiquement les bords transparents | [API](./trim/api.md) |
| [Rotation](./rotate/README.md) | Fait pivoter l'image | [API](./rotate/api.md) |
| [Miroir](./flip/README.md) | Retourne l'image horizontalement et/ou verticalement | [API](./flip/api.md) |
| [Distorsion](./skew/README.md) | Incline l'image (cisaillement horizontal et vertical) | [API](./skew/api.md) |
| [Perspective](./cornerPin/README.md) | Déplace librement les quatre coins de l'image pour la mettre en perspective | [API](./cornerPin/api.md) |
| [Sticker](./sticker/README.md) | Décolle l'image comme un sticker, en l'enroulant dans une direction choisie | [API](./sticker/api.md) |
| [Déplacement](./translate/README.md) | Déplace la texture en X et Y, en % de l'image | [API](./translate/api.md) |
| [Transformation](./transform/README.md) | Déplace, tourne, met à l'échelle, retourne et estompe l'image en une fois | [API](./transform/api.md) |
| [Marionnette](./puppet/README.md) | Déforme l'image en déplaçant des épingles sur un maillage (puppet warp) | [API](./puppet/api.md) |
| [Polaire](./polar/README.md) | Convertit entre coordonnées rectangulaires et polaires (anneaux, rayons, halos) | [API](./polar/api.md) |
| [Ondulation](./ripple/README.md) | Distorsion en anneaux concentriques autour d'un centre | [API](./ripple/api.md) |
| [Déplacement](./displace/README.md) | Déforme l'image selon une carte de déplacement (bruit, dégradé…) | [API](./displace/api.md) |
| [Remappage de texture](./remap/README.md) | Redessine l'image en lisant, pour chaque pixel, la position donnée par une carte (dégradé, bruit…) | [API](./remap/api.md) |
| [Kaléidoscope](./kaleidoscope/README.md) | Répète un secteur en symétrie radiale | [API](./kaleidoscope/api.md) |
| [Tourbillon](./twirl/README.md) | Tord l'image en spirale autour d'un centre | [API](./twirl/api.md) |
| [Onde](./wave/README.md) | Déplacement sinusoïdal horizontal / vertical | [API](./wave/api.md) |
| [Distorsion de lentille](./fisheye/README.md) | Bombe (fisheye) ou creuse (coussinet) l'image autour d'un centre | [API](./fisheye/api.md) |
| [Décalage raccord](./tile/README.md) | Décale l'image : vérifier et fabriquer des textures tileables | [API](./tile/api.md) |
| [Courber sur chemin](./warpPath/README.md) | Déforme une image le long d'un chemin (ruban / trail courbé) | [API](./warpPath/api.md) |
| [Suivre un chemin](./followPath/README.md) | Fait voyager une image le long d'un chemin, de 0 % à 100 % de sa longueur ; le chemin peut sortir du cadre | [API](./followPath/api.md) |
| [Découpe](./trimVideo/README.md) | Découpe une partie de la vidéo à un moment donné. | — |
| [Vitesse](./speedVideo/README.md) | Accélère ou ralentit la vidéo. La cadence de sortie reste la même : ce sont les images demandées à la source qui changent. | — |
| [Cadence](./frameRateVideo/README.md) | Réécrit la cadence de la vidéo. Baisser la cadence allège le fichier ; l'augmenter au-delà de la source duplique des images. | — |
