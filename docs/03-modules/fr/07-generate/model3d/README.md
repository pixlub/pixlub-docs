# Modèle 3D

Importe un modèle 3D (GLB, GLTF, OBJ, FBX, STL) : caméra, matériaux et animation. À fusionner sur une image via « Fusion Modèle 3D ».

**Catégorie** : Génération · **Identifiant** : `model3d`

## Où l'utiliser

- **[Graphe d'image](https://pixlub.com/fr/image/graph)** : Reliez-le à d'autres modules pour composer un effet plus complexe.

## Entrées

Ce module n’a pas d’entrée : il crée l’image à partir de ses seuls réglages.
