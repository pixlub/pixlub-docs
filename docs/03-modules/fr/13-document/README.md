# Documents

| Module | Description | API |
| --- | --- | --- |
| [Fusionner des PDF](./docMerge/README.md) | Assemble plusieurs PDF en un seul fichier, dans l’ordre choisi. | — |
| [Découper un PDF](./docSplit/README.md) | Sépare un PDF en plusieurs fichiers : page par page, par paquets, aux repères posés sur l’aperçu ou selon vos plages. À l’export, en PDF ou en images. | — |
| [Organiser les pages](./docPages/README.md) | Garde, supprime, réordonne, duplique ou tourne les pages d’un PDF. | — |
| [Rogner un PDF](./docCrop/README.md) | Retire une marge autour des pages, sans toucher à leur contenu : la même partout, ou propre à certaines pages. | — |
| [Numéroter les pages](./docPageNumbers/README.md) | Ajoute un numéro sur chaque page, à la place et au format de votre choix. | — |
| [Filigrane](./docWatermark/README.md) | Pose un texte ou une image translucide sur les pages, une fois ou en mosaïque. | — |
| [Métadonnées](./docMetadata/README.md) | Lit et modifie le titre, l’auteur, le sujet et les mots-clés d’un PDF, ou les efface. | — |
| [Signer un PDF](./docSign/README.md) | Pose votre signature, dessinée ou importée, sur les pages choisies. | — |
| [Images vers PDF](./docImagesToPdf/README.md) | Assemble des images en un PDF : composez vos pages, une ou plusieurs images chacune, placées où vous voulez. | — |
| [PDF vers images](./docPdfToImages/README.md) | Exporte chaque page en PNG, JPEG ou WebP, à la résolution choisie. | — |
| [PDF vers Word](./docPdfToWord/README.md) | Reprend les titres, paragraphes et tableaux d’un PDF dans un document Word modifiable. | — |
| [PDF vers Excel](./docPdfToExcel/README.md) | Range le contenu d’un PDF dans un classeur : les colonnes alignées deviennent des colonnes, les nombres des nombres. | — |
| [Office vers PDF](./docOfficeToPdf/README.md) | Convertit un document Word, Excel, PowerPoint ou OpenDocument en PDF. | — |
| [HTML vers PDF](./docHtmlToPdf/README.md) | Met en page un fichier HTML et le rend en PDF, texte sélectionnable compris. | — |
| [Compresser un PDF](./docCompress/README.md) | Réduit le poids d’un PDF en réencodant ses images ; le texte reste net et sélectionnable. | — |
| [Réparer un PDF](./docRepair/README.md) | Reconstruit un PDF endommagé ou qui s’ouvre mal : table des objets, catalogue et arbre des pages. | — |
| [Protéger un PDF](./docProtect/README.md) | Chiffre un PDF en AES-256 avec un mot de passe, et limite ce qu’on peut en faire. | — |
| [Déverrouiller un PDF](./docUnlock/README.md) | Retire le mot de passe et les restrictions d’un PDF protégé, si vous connaissez son mot de passe. | — |
| [Caviarder un PDF](./docRedact/README.md) | Noircit les mots ou motifs choisis : le texte disparaît vraiment de la page. | — |
| [Extraire le texte (OCR)](./docOcrText/README.md) | Lit le texte d’un PDF, d’un scan ou d’une photo de document, puis l’exporte en texte brut ou en PDF consultable. | — |
| [Comparer deux PDF](./docCompare/README.md) | Liste les lignes ajoutées et retirées page par page, et signale les pages dont l’aspect a changé. | — |
