# Office vers PDF

Convertir un document Word, Excel, PowerPoint ou OpenDocument en PDF.

**Catégorie** : Documents · **Identifiant** : `docOfficeToPdf`

## Où l'utiliser

- **[Page du module](https://pixlub.com/fr/module/docOfficeToPdf)** : Déposez vos fichiers, réglez, téléchargez : le module seul, sans rien d'autre.

## Utilisation

1. **Se connecter**

   La conversion passe par nos serveurs : un compte est demandé.

2. **Importer**

   Déposez un fichier .docx, .xlsx, .pptx, .odt…

3. **Lancer**

   Le prix en crédits s'affiche avant la conversion.

## Astuces

- La pastille de confidentialité indique « Envoyé au serveur » dès que le fichier est prêt à partir.
