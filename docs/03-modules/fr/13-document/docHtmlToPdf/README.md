# HTML vers PDF

Mettre en page un fichier HTML et le rendre en PDF, texte sélectionnable compris.

**Catégorie** : Documents · **Identifiant** : `docHtmlToPdf`

## Où l'utiliser

- **[Page du module](https://pixlub.com/fr/module/docHtmlToPdf)** : Déposez vos fichiers, réglez, téléchargez : le module seul, sans rien d'autre.

## Utilisation

1. **Se connecter**

   La mise en page passe par nos serveurs : un compte est demandé.

2. **Importer**

   Déposez un fichier .html.

3. **Lancer**

   Le prix en crédits s'affiche avant le rendu.

## Astuces

- Les images doivent être intégrées au fichier ou accessibles en ligne.
