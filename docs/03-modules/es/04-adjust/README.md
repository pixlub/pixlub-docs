# Ajuste

| Módulo | Descripción | API |
| --- | --- | --- |
| [Ajuste básico](./baseAdjust/README.md) | Los ajustes esenciales de una foto, reunidos: luz, tonos, balance de blancos y colores | [API](./baseAdjust/api.md) |
| [Niveles](./levels/README.md) | Ajusta los puntos negro y blanco, la gamma y el rango de salida, por canal | [API](./levels/api.md) |
| [Balance de blancos](./whiteBalance/README.md) | Calienta o enfría la imagen y corrige su dominante verde o magenta | [API](./whiteBalance/api.md) |
| [Recolorear](./recolor/README.md) | Tiñe toda la imagen de un solo color, conservando sus sombras y sus luces | [API](./recolor/api.md) |
| [HSL](./hsl/README.md) | Desplaza el tono, la saturación y la luminosidad de un rango de colores | [API](./hsl/api.md) |
| [Blanco y negro](./blackWhite/README.md) | Pasa la imagen a gris dosificando la luminosidad de cada color | [API](./blackWhite/api.md) |
| [Brillo y contraste](./brightness/README.md) | Ajusta el brillo y el contraste | [API](./brightness/api.md) |
| [Posterizar](./posterize/README.md) | Reduce el número de niveles por canal (tonos planos estilizados, cel shading) | [API](./posterize/api.md) |
| [Exposición](./exposure/README.md) | Sube o baja la luz de la imagen, paso a paso como una cámara fotográfica | [API](./exposure/api.md) |
| [Curvas](./curves/README.md) | Ajusta la tonalidad con una curva editable, por canal o global | [API](./curves/api.md) |
| [Curvas de saturación / tono](./hueSatCurves/README.md) | Ajusta la saturación o el tono según la luminancia, la saturación o el tono de cada color | [API](./hueSatCurves/api.md) |
| [Mezclador de canales](./channelMixer/README.md) | Recompone cada canal a partir de los demás, en el espacio elegido | [API](./channelMixer/api.md) |
| [Invertir](./invert/README.md) | Pasa la imagen a negativo | [API](./invert/api.md) |
| [Equilibrio de color](./colorBalance/README.md) | Ajusta los tonos por rango tonal (claros, medios, oscuros), con máscara opcional | [API](./colorBalance/api.md) |
| [Filtro de accesibilidad](./colorAccessibility/README.md) | Corrige los colores para que sigan siendo legibles con una visión daltónica | [API](./colorAccessibility/api.md) |
| [Paleta: recolorear](./paletteRemap/README.md) | Genera una variante recoloreada de la imagen por cada color de la paleta (lote) | [API](./paletteRemap/api.md) |
| [Umbral](./threshold/README.md) | Binariza la luminancia según un umbral (con transición suave) | [API](./threshold/api.md) |
| [Reemplazar colores](./replaceColors/README.md) | Reemplaza una lista de colores de origen por colores de destino | [API](./replaceColors/api.md) |
| [Opacidad](./opacity/README.md) | Modifica la opacidad de la imagen | [API](./opacity/api.md) |
| [Contorno](./outline/README.md) | Añade un contorno a la imagen | [API](./outline/api.md) |
| [Sombra](./shadow/README.md) | Proyecta una sombra (exterior o interior) a partir del alfa de la imagen | [API](./shadow/api.md) |
| [Mapa de degradado](./gradientMap/README.md) | Colorea la imagen asignando su luminancia a un degradado | [API](./gradientMap/api.md) |
