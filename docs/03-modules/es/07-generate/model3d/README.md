# Modelo 3D

Importa un modelo 3D (GLB, GLTF, OBJ, FBX, STL): cámara, materiales y animación. Para fusionarlo sobre una imagen, use «Fusión de modelo 3D».

**Categoría** : Generación · **Identificador** : `model3d`

## Dónde usarlo

- **[Grafo de imagen](https://pixlub.com/es/image/graph)** : Conéctelo a otros módulos para componer un efecto más complejo.

## Entradas

Este módulo no tiene entrada: crea la imagen solo a partir de sus ajustes.

> [!NOTE]
> **Guía en preparación**
>
> Este módulo todavía no tiene una guía detallada. Sus ajustes muestran su descripción en la aplicación; la vista API enumera cada uno de ellos con sus límites.
