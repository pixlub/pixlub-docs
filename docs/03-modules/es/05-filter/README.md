# Filtros

| Módulo | Descripción | API |
| --- | --- | --- |
| [Desenfoque](./blur/README.md) | Desenfoque gaussiano, de movimiento, de rotación o de zoom (centro interactivo) | [API](./blur/api.md) |
| [Desenfoque de movimiento](./motionBlur/README.md) | Desenfoque direccional, de zoom o de rotación (velocidad, estelas, impactos) | [API](./motionBlur/api.md) |
| [Nitidez](./sharpen/README.md) | Refuerza los detalles y los contornos (máscara de enfoque) | [API](./sharpen/api.md) |
| [Reducción de ruido](./denoise/README.md) | Reduce el ruido conservando los contornos (filtro de mediana) | [API](./denoise/api.md) |
| [Detección de contornos](./edgeDetect/README.md) | Extrae los contornos (Sobel) con doble umbral, colores y desenfoque previo | [API](./edgeDetect/api.md) |
| [Aberración cromática](./chromatic/README.md) | Desplaza los canales rojo y azul (efecto de lente, glitch, impacto) | [API](./chromatic/api.md) |
| [Dilatar / Erosionar](./morphology/README.md) | Engrosa o contrae las zonas opacas (máscaras, contornos, siluetas) | [API](./morphology/api.md) |
| [Mapa de normales](./normalMap/README.md) | Genera un mapa de normales a partir de un mapa de alturas (relieve para motores 3D / VFX) | [API](./normalMap/api.md) |
| [Pixelar](./pixelate/README.md) | Reduce la imagen a píxeles grandes (efecto pixel art) | [API](./pixelate/api.md) |
| [Semitono](./halftone/README.md) | Trama de puntos, tramado ordenado (Bayer) o difusión de error (retro / impresión) | [API](./halftone/api.md) |
| [Pintura](./kuwahara/README.md) | Manchas pictóricas que conservan los contornos (filtro de Kuwahara, efecto óleo) | [API](./kuwahara/api.md) |
| [Ordenación de píxeles](./pixelSort/README.md) | Ordena los píxeles por luminancia en las zonas claras u oscuras (glitch art) | [API](./pixelSort/api.md) |
| [Líneas CRT](./scanlines/README.md) | Líneas de barrido y máscara RGB al estilo de una pantalla de tubo | [API](./scanlines/api.md) |
| [Rayos de luz](./rays/README.md) | Rayos volumétricos emitidos por las zonas claras desde un centro (god rays) | [API](./rays/api.md) |
| [Borde difuminado](./feather/README.md) | Suaviza los bordes de la transparencia (fundido de la máscara alfa) | [API](./feather/api.md) |
| [Viñeta](./vignette/README.md) | Oscurece progresivamente los bordes de la imagen | [API](./vignette/api.md) |
| [Bloom](./bloom/README.md) | Difunde las zonas luminosas en un halo aditivo (glow) | [API](./bloom/api.md) |
| [Quitar un fondo liso](./removeBg/README.md) | Vuelve transparente un fondo de un solo color (pantalla verde, estudio…), detectado o elegido. | [API](./removeBg/api.md) |
| [Separar RGB](./splitRgb/README.md) | Separa la imagen en sus canales rojo, verde y azul | [API](./splitRgb/api.md) |
| [Separar transparencia](./splitAlpha/README.md) | Separa la imagen en su canal de color (RGB opaco) y su canal alfa (escala de grises) | [API](./splitAlpha/api.md) |
| [Purpurina](./glitter/README.md) | Cubre la imagen de purpurina centelleante: escamas irisadas, destellos de estrella y un reflejo que barre, en bucle. | [API](./glitter/api.md) |
