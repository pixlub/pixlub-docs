# Conversión

| Módulo | Descripción | API |
| --- | --- | --- |
| [Extracción de audio](./extractAudioVideo/README.md) | Extrae la pista de sonido de un video a un archivo de audio: MP3, AAC, Opus, FLAC, WAV… o la pista original tal cual, sin pérdida. | — |
| [Conversión de audio](./convertAudio/README.md) | Convierte un archivo de sonido a otro formato (MP3, AAC, Opus, Vorbis, FLAC, WAV o AIFF), con su tasa de bits, su frecuencia y sus canales, y conserva la parte que quiera. | — |
| [Conversión](./convert/README.md) | Convierte imágenes, animaciones, videos y audios a cualquier formato de exportación: PNG, JPG, WebP, GIF, MP4, WebM, MP3, FLAC, WAV, PDF… | [API](./convert/api.md) |
