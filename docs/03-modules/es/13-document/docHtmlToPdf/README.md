# HTML a PDF

Maquetar un archivo HTML y generarlo en PDF, con el texto seleccionable incluido.

**Categoría** : Documentos · **Identificador** : `docHtmlToPdf`

## Dónde usarlo

- **[Página del módulo](https://pixlub.com/es/module/docHtmlToPdf)** : Suelte sus archivos, ajuste y descargue: el módulo por sí solo, sin nada más.

## Uso

1. **Iniciar sesión**

   La maquetación pasa por nuestros servidores: se pide una cuenta.

2. **Importar**

   Suelte un archivo .html.

3. **Iniciar**

   El precio en créditos se muestra antes de generarlo.

## Consejos

- Las imágenes deben estar integradas en el archivo o ser accesibles en línea.
