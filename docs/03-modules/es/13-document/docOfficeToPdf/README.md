# Office a PDF

Convertir un documento de Word, Excel, PowerPoint u OpenDocument a PDF.

**Categoría** : Documentos · **Identificador** : `docOfficeToPdf`

## Dónde usarlo

- **[Página del módulo](https://pixlub.com/es/module/docOfficeToPdf)** : Suelte sus archivos, ajuste y descargue: el módulo por sí solo, sin nada más.

## Uso

1. **Iniciar sesión**

   La conversión pasa por nuestros servidores: se pide una cuenta.

2. **Importar**

   Suelte un archivo .docx, .xlsx, .pptx, .odt…

3. **Iniciar**

   El precio en créditos se muestra antes de la conversión.

## Consejos

- La insignia de privacidad indica «Enviado al servidor» en cuanto el archivo está listo para enviarse.
