# Documentos

| Módulo | Descripción | API |
| --- | --- | --- |
| [Unir PDF](./docMerge/README.md) | Reúne varios PDF en un solo archivo, en el orden que elija. | — |
| [Dividir un PDF](./docSplit/README.md) | Separa un PDF en varios archivos: página por página, por bloques, en las marcas colocadas en la vista previa o según sus rangos. Se exporta en PDF o en imágenes. | — |
| [Organizar las páginas](./docPages/README.md) | Conserva, elimina, reordena, duplica o gira las páginas de un PDF. | — |
| [Recortar un PDF](./docCrop/README.md) | Quita un margen alrededor de las páginas, sin tocar su contenido: el mismo en todas o uno propio para algunas páginas. | — |
| [Numerar las páginas](./docPageNumbers/README.md) | Añade un número en cada página, en el lugar y con el formato que elija. | — |
| [Marca de agua](./docWatermark/README.md) | Coloca un texto o una imagen translúcidos sobre las páginas, una vez o en mosaico. | — |
| [Metadatos](./docMetadata/README.md) | Lee y modifica el título, el autor, el asunto y las palabras clave de un PDF, o los borra. | — |
| [Firmar un PDF](./docSign/README.md) | Coloca su firma, dibujada o importada, en las páginas que elija. | — |
| [Imágenes a PDF](./docImagesToPdf/README.md) | Reúne imágenes en un PDF: componga sus páginas, con una o varias imágenes cada una, colocadas donde quiera. | — |
| [PDF a imágenes](./docPdfToImages/README.md) | Exporta cada página en PNG, JPEG o WebP, a la resolución elegida. | — |
| [PDF a Word](./docPdfToWord/README.md) | Lleva los títulos, los párrafos y las tablas de un PDF a un documento de Word editable. | — |
| [PDF a Excel](./docPdfToExcel/README.md) | Ordena el contenido de un PDF en un libro de cálculo: las columnas alineadas se convierten en columnas y los números, en números. | — |
| [Office a PDF](./docOfficeToPdf/README.md) | Convierte un documento de Word, Excel, PowerPoint u OpenDocument en PDF. | — |
| [HTML a PDF](./docHtmlToPdf/README.md) | Maqueta un archivo HTML y lo convierte en PDF, con texto seleccionable. | — |
| [Comprimir un PDF](./docCompress/README.md) | Reduce el peso de un PDF recodificando sus imágenes; el texto sigue nítido y seleccionable. | — |
| [Reparar un PDF](./docRepair/README.md) | Reconstruye un PDF dañado o que se abre mal: tabla de objetos, catálogo y árbol de páginas. | — |
| [Proteger un PDF](./docProtect/README.md) | Cifra un PDF en AES-256 con una contraseña y limita lo que se puede hacer con él. | — |
| [Desbloquear un PDF](./docUnlock/README.md) | Quita la contraseña y las restricciones de un PDF protegido, si conoce su contraseña. | — |
| [Censurar un PDF](./docRedact/README.md) | Tapa en negro las palabras o los patrones elegidos: el texto desaparece realmente de la página. | — |
| [Extraer el texto (OCR)](./docOcrText/README.md) | Lee el texto de un PDF, de un escaneo o de una foto de documento y lo exporta como texto sin formato o como PDF con búsqueda. | — |
| [Comparar dos PDF](./docCompare/README.md) | Enumera las líneas añadidas y eliminadas página por página, y señala las páginas cuyo aspecto ha cambiado. | — |
