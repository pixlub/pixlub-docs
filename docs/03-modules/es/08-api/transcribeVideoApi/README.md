# Subtítulos (video)

Transcribir la voz de un video, palabra por palabra, e incrustar los subtítulos en la imagen.

**Categoría** : Servicios de API · **Identificador** : `transcribeVideoApi`

## Dónde usarlo

- **[Editor de video](https://pixlub.com/es/video/editor)** : Añádalo como efecto en un clip del montaje.

## Entradas

Los archivos que acepta la página del módulo: suéltelos en la zona de importación o haga clic en ella para buscarlos. Un archivo de otro formato se descarta, con un mensaje que recuerda los formatos permitidos.

| Entrada | Formatos aceptados | Archivos |
| --- | --- | --- |
| **Video** (obligatoria)<br />Video cuya pista de sonido se envía una vez al servidor para transcribirla; los subtítulos se incrustan en el navegador. | `MP4`, `WebM`, `MOV`, `MKV` | Un archivo |

## Uso

1. **Iniciar sesión**

   La transcripción pasa por nuestros servidores: se pide una cuenta.

2. **Importar**

   Suelte un video; solo se envía su pista de audio, una vez.

3. **Dar formato**

   Fuente, colores, posición, estilos y resaltado de la palabra pronunciada, calculados en su navegador.

## Ajustes

| Ajuste | Efecto |
| --- | --- |
| **Transcripción** | Idioma original, caracteres por subtítulo. |
| **Texto** | Fuente, tamaño, color, contorno, posición y ancho. |
| **Estilos** | Fondo, sombra, resplandor… apilados como en el módulo Texto. |
| **Resaltado** | Palabra pronunciada iluminada, o texto que aparece letra a letra. |

## Consejos

- Indique el idioma original si el video empieza con música.

## Exportación

El resultado se exporta desde la página del módulo o desde el editor de video, en MP4, WebM u otro contenedor de video, sin salir de su navegador.

- **[El editor de video](../../../../01-app/es/03-video/01-video-editor.md)** : Editar, ajustar los efectos y exportar un video.
