# App overview

The tools of the Pixlub site, what they do, and when to pick one over another.

The Pixlub site is an editor that opens in your browser, with nothing to install. Every tool draws from the same catalog of **modules**: a module is one operation (blur, resize, remove a background, merge two PDFs…) with its settings.

## The tools

- **[Standalone module](./01-module-independant.md)** : One module on its own page: drop, adjust, download.
- **[Image graph](./02-image/01-image-graph.md)** : Connect modules to build an effect, animate it and export it.
- **[Image converter](./02-image/02-image-converter.md)** : Change the format of your images, one by one or in batches.
- **[Adjustment editor](./02-image/03-image-adjust.md)** : Stack brightness, curves, hue… on the same image.
- **[Video editor](./03-video/01-video-editor.md)** : Edit clips, sounds, texts and subtitles together.
- **[Documents](./04-document.md)** : Merge, sign, compress and convert your PDFs.

## Which tool to choose

- **One operation on one or more files**: the module page. It is the most direct.
- **Several chained operations, or an image built from several sources**: the image graph.
- **Only a format change**: the converter.
- **Fixing colors and light**: the adjustment editor.
- **A video to edit**: the video editor. For a single operation on a video (trim, speed up), its module page is enough.

## What every tool shares

- **Local processing.** Modules run in your browser. Only AI modules and a few export formats go through our servers, and a badge at the bottom of the screen always says so. See [Local and server processing](./06-privacy.md).
- **Live preview.** Every setting you change recomputes the preview; the export is full resolution.
- **Shared export.** Every tool uses the same format catalog (PNG, JPG, WebP, AVIF, GIF, MP4, WebM…) and the same export window.
- **Optional account.** Without an account, every local module stays available. The account is for AI modules, credits and your plan limits: see [Account and credits](./05-account-and-credits.md).
