# Adjustment editor

Stack several color and light adjustments on the same image, and compare with the original.

The [adjustment editor](https://pixlub.com/en/module/allAdjustment) gathers every module of the **Adjustment** category (brightness, exposure, curves, levels, hue and saturation, white balance…) on a single page. Instead of chaining module pages, you build a **stack** of adjustments applied in order.

The [Adjust images](https://pixlub.com/en/image/adjust) page shows each adjustment in pictures and opens the editor with the one you pick.

## Using the editor

1. **Drop the image**

   Drag one or more images into the drop zone.

2. **Add adjustments**

   **Add an adjustment** opens the catalog. Each added adjustment joins the stack.

3. **Adjust and reorder**

   Pick an adjustment in the stack to show its options. Drag it to change the order: each adjustment applies to the result of the previous ones.

4. **Compare and export**

   **Compare with the original** shows before and after. The export applies the whole stack in full resolution.

## Blending and opacity

Each adjustment has a **blend mode** and an **opacity**: you can, for example, apply black and white at 40% to slightly desaturate, or a curve in Overlay mode.
