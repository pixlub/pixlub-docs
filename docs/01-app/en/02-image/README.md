# Image

Pixlub image tools and modules, by category.

Image modules are used on their own page, chained in the [image graph](./01-image-graph.md), and many of them can also be called through the [API](../../../02-api/en/01-getting-started.md).

- **[Image graph](./01-image-graph.md)** : Connect modules to build an effect.
- **[Converter](./02-image-converter.md)** : Change the format of your images.
- **[Adjustment editor](./03-image-adjust.md)** : Stack color and light adjustments.

## Categories

| Category | What you find there |
| --- | --- |
| Transform | Size, crop, rotation, perspective, and warps: waves, twirl, polar, puppet, bend along a path. |
| Adjustment | Light and color: levels, curves, exposure, hue and saturation, black and white, outline and shadow. |
| Filters | Blurs, sharpening, denoising, style effects (pixel, halftone, paint, CRT) and light (bloom, rays, vignette). |
| Compose | Merge images, apply a mask, split or join channels, arrange a batch or a sprite sheet. |
| Generation | Create images without a source: noise, solids, patterns, palettes, glows, lightning, particles, paths. |
| API services | AI modules, computed on our servers: background removal, face blur, decal. |
| Text | Write a text and render it as an image. |
| Conversion | Change a file's format. |
| Graph blocks | Sources, outputs, values and colors: they only exist in the [graph](./01-image-graph.md), to feed other modules. |

> [!TIP]
> **Where to use them**
>
> Each module page says whether it has its own page, whether it works in the graph, and whether the API can call it.
