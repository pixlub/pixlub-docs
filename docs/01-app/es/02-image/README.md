# Imagen

Las herramientas y los módulos de imagen de Pixlub, por categoría.

Los módulos de imagen se usan solos en su página, se encadenan en el [grafo de imagen](./01-image-graph.md), y buena parte de ellos también se llama mediante la [API](../../../02-api/es/01-getting-started.md).

- **[Grafo de imagen](./01-image-graph.md)** : Conectar módulos para componer un efecto.
- **[Conversor](./02-image-converter.md)** : Cambiar el formato de sus imágenes.
- **[Editor de ajustes](./03-image-adjust.md)** : Apilar los ajustes de color y de luz.

## Las categorías

| Categoría | Qué contiene |
| --- | --- |
| Transformación | Tamaño, recorte, rotación, perspectiva y las deformaciones: ondas, remolino, polar, marioneta, curvatura a lo largo de un trazado. |
| Ajuste | Luz y color: niveles, curvas, exposición, tono y saturación, blanco y negro, contorno y sombra. |
| Filtros | Desenfoques, nitidez, reducción de ruido, efectos de estilo (píxel, semitono, pintura, CRT) y de luz (resplandor, rayos, viñeta). |
| Composición | Fusionar imágenes, aplicar una máscara, separar o reunir canales, organizar un lote o una hoja de sprites. |
| Generación | Crear imagen sin origen: ruido, colores sólidos, patrones, paletas, brillos, rayos, partículas, trazados. |
| Servicios de API | Los módulos de IA, calculados en nuestros servidores: quitar el fondo, desenfoque de rostros, calcomanía. |
| Texto | Escribir un texto y convertirlo en imagen. |
| Conversión | Cambiar el formato de un archivo. |
| Bloques del grafo | Orígenes, salidas, valores y colores: solo existen en el [grafo](./01-image-graph.md), para alimentar a los demás módulos. |

> [!TIP]
> **Dónde usarlos**
>
> Cada ficha de módulo indica si tiene su propia página, si se usa en el grafo y si se puede llamar mediante la API.
