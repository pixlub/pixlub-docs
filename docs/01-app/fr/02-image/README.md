# Image

Les outils et les modules d'image de Pixlub, par catégorie.

Les modules d'image s'utilisent seuls sur leur page, s'enchaînent dans le [graphe d'image](./01-image-graph.md), et une bonne partie s'appelle aussi par l'[API](../../../02-api/fr/01-getting-started.md).

- **[Graphe d'image](./01-image-graph.md)** : Relier des modules pour composer un effet.
- **[Convertisseur](./02-image-converter.md)** : Changer le format de vos images.
- **[Éditeur de réglages](./03-image-adjust.md)** : Empiler les réglages de couleur et de lumière.

## Les catégories

| Catégorie | Ce qu'on y trouve |
| --- | --- |
| Transformation | Taille, recadrage, rotation, perspective, et les déformations : ondes, tourbillon, polaire, marionnette, courbure sur un chemin. |
| Ajustement | Lumière et couleur : niveaux, courbes, exposition, teinte et saturation, noir et blanc, contour et ombre. |
| Filtres | Flous, netteté, débruitage, effets de style (pixel, demi-teinte, peinture, CRT) et lumière (bloom, rayons, vignette). |
| Composition | Fusionner des images, appliquer un masque, séparer ou assembler des canaux, disposer un lot ou une planche de sprites. |
| Génération | Créer de l'image sans source : bruit, aplats, motifs, palettes, lueurs, éclairs, particules, tracés. |
| Services API | Les modules d'IA, calculés sur nos serveurs : détourage, floutage des visages, décalcomanie. |
| Texte | Écrire un texte et le rendre en image. |
| Conversion | Changer le format d'un fichier. |
| Blocs du graphe | Sources, sorties, valeurs et couleurs : ils n'existent que dans le [graphe](./01-image-graph.md), pour alimenter les autres modules. |

> [!TIP]
> **Où les utiliser**
>
> Chaque fiche de module précise s'il a sa propre page, s'il s'utilise dans le graphe, et s'il est appelable par l'API.
