# Vidéo

L'éditeur vidéo et les modules vidéo de Pixlub, par catégorie.

La vidéo se travaille de deux façons : un module seul sur sa page, pour une opération rapide (couper, accélérer), ou l'[éditeur vidéo](./01-video-editor.md) pour un vrai montage. Dans les deux cas, le décodage, le rendu et l'encodage se font dans votre navigateur.

- **[Éditeur vidéo](./01-video-editor.md)** : Monter des plans, des sons, des textes et des sous-titres.

## Les catégories

| Catégorie | Ce qu'on y trouve |
| --- | --- |
| Transformation | Découper une vidéo, changer sa vitesse ou sa cadence. |
| Conversion | Extraire la piste son d'une vidéo. |
| Services API | Floutage automatique des visages et sous-titres générés depuis le son : ces deux modules envoient la vidéo ou son audio à nos serveurs. |

Dans l'éditeur vidéo, les modules d'image se posent aussi en **effet** sur un plan : flous, réglages de couleur, déformations… s'appliquent image par image.

> [!NOTE]
> **Pas d'appel par l'API**
>
> Les modules vidéo tournent dans votre navigateur : ils ne sont pas exposés par l'API publique.
